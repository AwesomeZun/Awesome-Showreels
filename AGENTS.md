# Agent instructions

This repo ships one skill: **motion-showreel** (turn a repo, paper, deck or website into a motion-graphics showreel).

When the user asks for a showreel, sizzle reel, teaser or explainer video, read and follow
`skills/motion-showreel/SKILL.md`. Its tools are plain Python and Node command-line programs, so any coding agent can
run them. Use the absolute path of `skills/motion-showreel` wherever the instructions write `$S`.
