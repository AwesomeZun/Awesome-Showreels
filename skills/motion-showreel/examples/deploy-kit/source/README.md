# Deploy Kit

> 작은 제품을 세상에 내놓는 도구.

Deploy Kit은 사이드 프로젝트를 공개할 때마다 반복하는 설정 파일과 화면을 한곳에서 찍어 내는 **출시 준비 작업대**입니다. 프로젝트 이름과 주소, 스택을 입력하면 README부터 CI 워크플로, 배포 설정, SEO 메타 태그, OG 이미지, 파비콘까지 실시간으로 만들어지고, 필요한 것만 골라 ZIP 하나로 가져갈 수 있습니다.

toyz 마켓플레이스에 예시로 올라 있던 프로젝트 “Deploy Kit”(사이드 프로젝트 스타터)을 실제로 작동하는 앱으로 구현했습니다.

## 주요 기능

- **프로젝트 설정** — 이름, 한 줄 소개, 설명, 배포 URL, 저장소 URL, 만든이, 이메일, 언어, 스택 프리셋(Vite + React, Next.js, Astro, SvelteKit, 정적 HTML), 패키지 매니저(npm, pnpm, yarn, bun), 배포 대상(Vercel, Netlify, Cloudflare Pages, GitHub Pages), 라이선스(MIT, Apache-2.0, 없음), 브랜드 색을 입력합니다. 주소·이메일 형식 오류와 브랜드 색의 글자 대비를 바로 알려 드립니다.
- **실시간 출력 트레이** — 입력하는 즉시 바뀐 파일이 오른쪽 트레이에서 반짝이고, OG 이미지와 파비콘 썸네일도 함께 갱신됩니다.
- **파일 생성기** — README.md, LICENSE, .gitignore, .env.example, .editorconfig, 배포 대상별 설정 파일(vercel.json / netlify.toml / wrangler.toml / GitHub Pages 워크플로), .github/workflows/ci.yml, robots.txt, sitemap.xml, site.webmanifest, SEO·Open Graph 메타 태그 스니펫, CHANGELOG.md, CONTRIBUTING.md, 이슈·PR 템플릿, 404.html, 디자인 토큰(tokens.css), 컴포넌트 CSS를 만듭니다. 파일마다 미리보기, 복사, 개별 다운로드, ZIP 포함 여부 토글이 있습니다.
  - 스택에 따라 빌드 명령·출력 폴더·환경 변수 접두사·정적 자산 폴더(public/, static/, 루트)가 바뀝니다.
  - 패키지 매니저에 따라 CI의 설치 단계(pnpm/action-setup, corepack, oven-sh/setup-bun)와 명령이 바뀝니다.
  - 설정값의 따옴표·꺾쇠·앰퍼샌드·개행은 HTML·XML·YAML·TOML·JSON 문법에 맞게 이스케이프합니다. 붙여 넣기로 섞여 들어온 제어 문자는 지우고, `.env.example` 값은 `#`·`$`·따옴표가 있으면 따옴표로 감싸고 `$`를 `\$`로 바꿉니다.
- **ZIP 일괄 다운로드** — 선택한 파일과 이미지 자산을 `프로젝트-슬러그/` 폴더 아래에 원래 구조 그대로 담습니다. 슬러그는 영문 소문자·숫자·하이픈만 쓰고 한글 이름은 로마자로 옮깁니다(예: “오르빗 노트” → `oreubit-noteu/`). 그래서 macOS의 `unzip` 같은 오래된 도구에서도 풀리고, Cloudflare `wrangler.toml`의 `name` 규칙에도 맞습니다. 헤더와 모바일 오른쪽 아래의 ZIP 버튼에 담길 항목 수가 표시됩니다.
- **OG 이미지 생성기** — 1200×630 Canvas에 포스터·분할·그리드·카드 4가지 레이아웃으로 제목·부제·배지를 그립니다. 브랜드 색과 홀로그래픽 리본 매듭이 들어가고, PNG로 받거나 ZIP에 넣을 수 있습니다.
- **파비콘 생성기** — 이니셜이나 기호(최대 3글자), 모양(원·둥근 사각·사각), 배경·글자색으로 favicon.svg와 PNG 32·180·192·512를 만듭니다. apple-touch-icon(180)은 iOS가 모서리를 직접 깎도록 꽉 찬 사각으로 그립니다. 파비콘을 포함하면 매니페스트 아이콘 항목과 메타 태그 아이콘 링크가 자동으로 채워집니다.
- **출시 체크리스트** — 기본 설정, SEO·공유, 성능, 접근성, 법적 고지, 분석·모니터링, 출시 당일 7개 분류 42개 항목입니다. 항목마다 설명, 완료 체크, 메모, 해당 없음 처리가 있고 진행률과 분류별 막대가 보입니다. 마크다운으로 복사하거나 내려받을 수 있습니다.
- **기본 컴포넌트 갤러리** — 버튼, 입력, 선택, 토글, 카드, 배지, 토스트, 모달, 빈 상태, 스켈레톤 10종을 브랜드 색 토큰을 입혀 실제로 눌러 볼 수 있게 보여 드립니다. HTML·CSS 코드를 복사할 수 있고, `:root` 토큰 파일(styles/tokens.css)과 컴포넌트 CSS(styles/components.css)가 ZIP에 들어갑니다.
- **링크 미리보기**(추가 기능) — 메타 태그가 검색 결과와 메신저 링크 카드에서 어떻게 보이는지 미리 보고, 제목·설명 길이를 알려 드립니다. 채널 프리셋이 있는 UTM 링크 빌더로 공유 링크를 만들어 복사할 수 있습니다.
- **키트 관리** — 프로젝트마다 키트를 여러 개 저장하고 전환·복제·삭제(되돌리기 가능)할 수 있습니다. 키트 하나 또는 전체를 JSON으로 내보내고 다시 가져올 수 있습니다. 예시 데이터 지우기와 전체 초기화는 확인 절차를 거칩니다.

## 사용 방법

1. 처음 열면 예시 키트 두 개(Orbit Note, Tiny Beat)가 들어 있습니다. 헤더의 `+` 버튼으로 새 키트를 만들거나 예시를 고쳐 써 보세요.
2. **01 프로젝트 설정**에서 값을 입력하면 오른쪽 트레이에서 바뀐 파일이 바로 표시됩니다.
3. **02 파일**에서 내용을 확인하고, 필요 없는 파일은 체크를 끕니다.
4. **03 OG 이미지**, **04 파비콘**에서 이미지를 다듬습니다.
5. 헤더의 **ZIP 받기**를 누르면 `프로젝트-슬러그-deploy-kit.zip`이 내려받아집니다. 압축을 풀어 저장소에 그대로 복사하면 됩니다.
6. **05 출시 체크리스트**로 남은 일을 확인하고 마크다운으로 팀과 공유합니다.

키보드만으로도 모든 흐름을 쓸 수 있습니다. 첫 Tab은 “본문으로 건너뛰기” 링크이고, 섹션을 옮기면 새 섹션 제목으로 포커스가 이동합니다.

## 실행·빌드·테스트

Node.js 20.19 이상이 필요합니다.

```sh
npm install
npm run dev          # 개발 서버
npm run build        # 타입 검사 + 프로덕션 빌드(dist/)
npm run lint         # oxlint
npm run preview      # 빌드 결과 미리보기
npm run test:domain  # 도메인 로직 검증(아래 참고)
PORT=4306 npm run test:smoke  # 빌드 후 헤드리스 Chrome 스모크 테스트
```

- `test:domain`은 스택 5 × 패키지 매니저 4 × 배포 대상 4 × 라이선스 3 × 언어 2 = 480가지 조합을 특수문자가 섞인 설정값으로 생성해, YAML(PyYAML)·TOML(tomllib)·XML(xmllint)·JSON 문법과 ZIP 구조(unzip)를 확인합니다. `python3`(PyYAML 포함), `xmllint`, `unzip`이 필요합니다.
- `test:smoke`는 설치된 Chrome을 헤드리스로 띄워 22개 사용자 흐름을 확인합니다(15~22번은 QA와 출고 점검에서 찾은 결함의 회귀 시나리오입니다). 실제로 ZIP을 내려받아 풀고 파일 구조, YAML·TOML·XML·JSON 문법, PNG 해상도(1200×630, 32, 180, 192, 512)와 픽셀(브랜드 색, 투명 모서리)까지 검사합니다. 스크린샷은 `tests/artifacts/`에 남습니다.

## 기술 구성

- Vite 8, React 19, TypeScript 6(strict), oxlint
- [fflate](https://github.com/101arrowz/fflate) — 브라우저 안에서 ZIP을 만듭니다.
- Pretendard Variable(본문), JetBrains Mono(보조 라벨·코드) — 모두 npm 패키지로 자체 호스팅합니다.
- OG 이미지와 파비콘은 Canvas 2D로, 리본 매듭 그림은 직접 만든 세잎 매듭 기하 함수(`src/domain/knot.ts`)로 SVG·Canvas에 그립니다.
- 구조
  - `src/domain/` — 순수 함수(파일 생성기, 이스케이프, 색 계산, 체크리스트, 저장 정규화, ZIP, OG·파비콘 그리기)
  - `src/app/` — 상태(리듀서·컨텍스트), 해시 라우팅, 다운로드, 토스트, 확인 대화 상자
  - `src/sections/` — 섹션 화면 8개
  - `src/ui/` — 공용 컴포넌트(입력 부품, 코드 보기, 캔버스, 키트 카드, 뼈대)
- 화면 전환은 해시 라우팅(`#/files/readme`)이라 서버 rewrite 설정이 필요 없습니다.

## 데이터 저장 방식과 개인정보

- 모든 키트는 이 브라우저의 `localStorage`에 `toyz-deploy-kit:state` 키로 저장됩니다(스키마 버전 필드 포함). 서버로 전송하지 않고, 외부 네트워크 요청도 하지 않습니다.
- 입력은 잠깐 모았다가(120ms) 저장하고, 새로고침·탭 닫기·백그라운드 전환 직전에는 바로 저장합니다.
- 같은 앱을 여러 탭에서 열어 두면 한 탭의 저장이 다른 탭에 곧바로 반영됩니다. 오래된 탭이 새 내용을 덮어쓰지 않습니다.
- 저장에 실패하면(저장 공간 부족, 사이트 데이터 차단) 상단 띠가 “저장 안 됨”으로 바뀌고 본문 위에 경고와 JSON 내보내기·다시 저장 버튼이 나타납니다.
- 저장된 데이터가 손상되면 읽을 수 있는 부분만 복구합니다. 전혀 읽을 수 없으면 원본을 `toyz-deploy-kit:backup` 키에 옮겨 둔 뒤 예시 데이터로 다시 시작하고, 화면에서 원본을 내려받을 수 있게 알려 드립니다. 화면 오류가 나면 오류 화면에서 저장된 데이터를 내려받거나(확인 후) 초기화할 수 있습니다.
- JSON 가져오기는 2MB·키트 200개까지 받습니다. 값은 입력 칸 길이(이름 80자, 설명 1,200자 등)로 자르고, 한 파일 안에서 id가 겹치면 새 id를 붙입니다.
- 다른 기기로 옮기려면 **08 키트 관리**의 JSON 내보내기·가져오기를 이용해 주세요.

## 알려진 한계

- 생성 문서의 본문은 한국어 또는 영어입니다. 한국어가 아닌 언어를 고르면 영어 본문에 `lang`·`og:locale`만 고른 언어로 들어갑니다.
- favicon.svg는 웹폰트를 담을 수 없어 브라우저 탭에서는 시스템 글꼴로 글자를 그립니다. PNG 아이콘은 Pretendard로 그려서 글자 모양이 조금 다를 수 있습니다.
- sitemap.xml에는 배포 URL 한 곳만 들어갑니다. 페이지가 늘어나면 직접 추가해야 합니다.
- GitHub Pages에서 저장소 이름 하위 경로(`/repo/`)로 배포하는 경우 스택별 base 경로 설정은 만들지 않습니다. Next.js를 GitHub Pages로 배포할 때는 `next.config`에 `output: 'export'`를 직접 지정해야 합니다(워크플로 주석으로 안내합니다).
- OG 이미지는 Canvas 기본 PNG 인코더를 써서 레이아웃에 따라 약 120KB(분할)~760KB(포스터)가 됩니다. 대부분의 공유 서비스 한도(수 MB) 안이지만 더 줄이려면 별도 도구로 압축해 주세요.
- UTM 링크 빌더의 입력값은 저장하지 않습니다.
- 파일을 하나씩 내려받을 때 브라우저가 `.gitignore`처럼 점으로 시작하는 이름에서 점을 빼고 저장합니다(보안 규칙). 이때 원래 이름을 알려 드리니 이름을 바꿔 주세요. ZIP에는 원래 이름 그대로 들어 있습니다.
- pnpm CI는 `pnpm/action-setup`에 `version: 10`을 적습니다. `package.json`에 `packageManager`가 있는 저장소라면 워크플로 주석대로 그 줄을 지워 주세요.
- 한글이 아닌 비라틴 문자(일본어·중국어 등)로만 된 이름은 슬러그가 `my-project`가 됩니다.
- 클립보드 복사는 보안 컨텍스트(HTTPS 또는 localhost)에서 가장 잘 동작하며, 그 밖에는 대체 방식을 씁니다.

## 출처

toyz 마켓플레이스의 예시 프로젝트를 실제 앱으로 구현했습니다. 예시 키트 속 인물·상호·서비스 이름(Orbit Note, 오하늘, Tiny Beat, Mina Seo 등)은 모두 가상입니다.
