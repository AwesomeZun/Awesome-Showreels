# OFFGRID — 관광지 밖에서 찾는 나만의 로컬 지도

동네 사람들이 남긴 산책 코스와 작은 가게를 모으는 지도 앱입니다. 관광 안내도에 없는 골목의 카페, 밥집, 빵집, 서점, 공방을 지도에 남기고, 그 사이를 잇는 산책 코스를 그려서 링크 하나로 나눌 수 있습니다.

지도가 주인공이고 패널은 가볍게 떠 있습니다. 라임(#D7F75B)과 거의 검정(#0B0B0C) 두 색으로 짰고, 지도는 CSS 필터로 어두운 모노 톤을 입힌 위에 라임 표식을 얹었습니다. 일반 지도 톤으로도 바꿀 수 있습니다.

> toyz 마켓플레이스의 예시 프로젝트를 실제 앱으로 구현했습니다.

## 주요 기능

- **지도**: Leaflet(npm 패키지)을 React에서 직접 감싸고 OpenStreetMap 타일을 씁니다. 저작권 표기(© OpenStreetMap contributors)는 지도 오른쪽 아래(모바일은 하단 시트 바로 위)에 늘 표시합니다. 표식은 모두 직접 그린 SVG(DivIcon)입니다. 멀리서 볼 때는 동네 이름표와 작은 점으로, 가까이 가면 분류 아이콘과 이름으로 바뀝니다.
- **장소**: 지도를 누르면 "여기에 장소 추가" 카드가 뜨고, 길게 누르면(데스크톱은 마우스를 누른 채 기다리거나 오른쪽 클릭) 바로 양식이 열립니다. 이름, 분류(카페·밥집·빵집·서점·공방·가게·산책·전망·기타), 한 줄 메모, 상세 메모, 별점, 태그, 가 봤어요·가고 싶어요, 즐겨찾기를 남길 수 있습니다. 수정, 삭제(알림에서 되돌리기), 선택한 마커를 끌어 위치 조정(되돌리기)이 됩니다.
- **산책 코스**: 코스 그리기를 켜고 지도를 누르면 경유점이 이어집니다. 점 끌어 옮기기, 점 골라 지우기, 골라 둔 점 뒤에 끼워 넣기, 방향 뒤집기, 모두 지우기, 되돌리기를 지원합니다. 총 거리(haversine)와 예상 시간(도보 시속 4.5km)이 실시간으로 바뀌고, 구간별 거리도 보여 줍니다. 코스 이름·설명·난이도·선 색을 정하고, 지도 위 장소 마커를 누르거나 "코스 근처 장소" 제안을 골라 경유 장소를 연결합니다.
- **목록과 지도 연동**: 목록에서 고르면 지도가 그 장소로 날아가고 마커가 강조됩니다. 목록 위에 마우스를 올리면 마커도 함께 들뜹니다. 마커를 누르면 상세 카드가 열립니다. 분류 필터, 검색(이름·메모·태그), 즐겨찾기, "지도 영역 안만"(패널에 가려진 부분은 빼고 실제로 보이는 영역 기준), 정렬(최근·이름·별점·가까운 순)을 제공합니다.
- **예시 데이터**: 서울 네 동네(성수·연남·을지로·서촌)에 가상의 상호명으로 된 장소 26곳과 코스 4개가 들어 있습니다. 목록과 상세에 "예시" 표시가 붙고, 위쪽 동네 바로가기로 바로 이동할 수 있습니다. 설정에서 예시 데이터를 지우거나(되돌리기 가능) 다시 넣을 수 있습니다. 다시 넣기는 빠진 예시만 채우고, 이미 있는 예시에 적어 둔 메모나 옮긴 위치는 덮어쓰지 않습니다.
- **내 위치**: 권한을 요청해 현재 위치를 표시하고 그곳으로 이동합니다. 거부·시간 초과·미지원일 때는 이유를 알려 줍니다. 가까운 순 정렬과 "내 위치에서 몇 m" 표시에 씁니다.
- **내보내기와 공유**: 장소와 코스를 GeoJSON으로(전체·고른 항목·코스 하나), 코스를 GPX로 내보냅니다. GeoJSON·GPX 파일을 가져올 때는 확장자보다 내용을 먼저 보고 형식을 가리며, 미리보기에서 넣을 항목을 고른 뒤 추가합니다. 한 번에 8MB, 장소와 코스를 합쳐 5,000개까지 가져올 수 있고, 브라우저 저장 공간에 다 들어가지 않으면 넣기 전에 알려 드립니다. 코스 하나, 장소 하나, 또는 여러 개를 고른 묶음을 URL 해시(`#/share/...`)에 담은 공유 링크로 만들 수 있고, 링크를 연 사람은 지도 위 미리보기를 본 뒤 자기 지도에 추가합니다.
- **모바일·태블릿**: 휴대폰(767px 이하)과 태블릿 세로 화면(1023px 이하 세로)에서는 지도가 전체 화면이고, 목록과 상세는 끌어올리는 하단 시트(접힘·반·전체 3단계)에 뜹니다. 손잡이를 끌거나 눌러 크기를 바꿉니다. 태블릿에서는 시트가 가운데 뜬 카드로 보이다가 다 펼치면 화면 폭을 채우고, 확대·축소 버튼도 함께 보입니다. 손가락으로 쓰는 기기에서는 터치 대상을 44px 이상으로 키웁니다.
- **인쇄용 코스 카드**: 코스 모양, 거리·시간, 경유 장소, 구간별 거리를 A4 한 장에 담은 카드를 미리 보고 인쇄할 수 있습니다. 출발·도착 지점과 같은 자리의 경유 장소 번호는 옆으로 비켜 세워 가리지 않고, PDF로 저장해도 여백이 흰색이고 오른쪽 테두리가 잘리지 않습니다.

## 사용 방법

1. 처음 열면 예시 데이터가 들어 있는 서울 지도가 보입니다. 위쪽 `01 성수` 같은 동네 버튼이나 지도 위 동네 이름표를 눌러 이동해 보세요.
2. 빈 곳을 누르고 **여기에 장소 추가**를 누르면 양식이 열립니다. 양식이 열린 동안 지도를 다시 누르면 새 장소의 위치가 바뀝니다.
3. 오른쪽 조작 버튼의 **코스 그리기**(또는 패널의 버튼)를 켜고 지도를 차례로 누르세요. 장소 마커를 누르면 그 자리에 점이 찍히고 경유 장소로 연결됩니다.
4. 상세 카드의 공유 버튼으로 링크를 만들고, **데이터·설정**에서 내보내기·가져오기와 예시 데이터 정리, 전체 초기화를 할 수 있습니다.

키보드로도 모든 핵심 흐름을 쓸 수 있습니다. Tab은 알림(되돌리기) → 동네 바로가기 → 패널(목록·양식) → 지도 조작 → 지도 표식 순서로 옮겨 가서, 표식이 많아도 목록에 바로 닿습니다. `장소 추가`는 지도 가운데(패널에 가리지 않은 곳)에 새 장소를 만들고, 코스 편집의 `가운데에 점`은 지도 가운데에 경유점을 찍습니다. 지도 마커는 Tab으로 옮겨 다니고 Enter로 엽니다.

| 키 | 동작 |
| --- | --- |
| Esc | 미리보기 닫기 → 추가 후보 닫기 → (코스 편집 중이면 고른 점 해제) → 편집 취소 → 목록으로 |
| Delete / Backspace | 코스 편집 중 고른 경유점 지우기 |
| Ctrl/⌘ + Z | 코스 편집 되돌리기 |

## 실행·빌드·테스트

Node.js 20.19 이상이 필요합니다.

```sh
npm install --no-audit --no-fund
npm run dev            # 개발 서버
npm run build          # 타입 검사 + 프로덕션 빌드(dist/)
npm run lint           # oxlint
npm run test:domain    # 순수 함수 검증(거리, GeoJSON·GPX 왕복, 공유 링크, 저장소 손상 방어, 되돌리기 병합 등 22건)
PORT=4310 npm run test:smoke      # 빌드 결과를 띄워 헤드리스 Chrome으로 사용자 흐름 45개 확인(QA 회귀 방지 11개 포함)
DEV_PORT=5310 npm run test:strict # 개발 서버(StrictMode)에서 지도가 한 번만 만들어지는지 확인
```

스모크 테스트는 `npm run build` 뒤에 실행합니다. 지도 타일 요청 실패는 앱 오류로 세지 않고, 타일이 실제로 뜨는지는 별도 단계로 확인합니다(네트워크가 없으면 `SKIP_TILES=1`). 스크린샷은 `tests/artifacts/`에 남습니다.

## 기술 구성

- Vite 8, React 19, TypeScript 6(strict), oxlint, playwright-core(테스트)
- Leaflet 1.9(react-leaflet 없이 직접 감쌈), OpenStreetMap 타일
- 글꼴: Pretendard Variable, JetBrains Mono(모두 npm 패키지로 자체 호스팅)
- 그 밖의 라이브러리 없이 직접 구현: haversine 거리, 점-경로 거리, GeoJSON·GPX 변환, 작은 XML 파서(GPX 읽기), 공유 링크 인코딩, 하단 시트

```
src/
  domain/      순수 함수: 타입, 거리 계산, 필터, 리듀서, 코스 초안, 저장소, GeoJSON, GPX, XML, 공유 링크, 예시 데이터
  map/         MapView — Leaflet 래퍼(StrictMode 이중 마운트 정리, ResizeObserver로 invalidateSize, DivIcon 표식)
  components/  목록, 상세, 양식, 코스 편집기, 미리보기, 대화상자, 패널·하단 시트, 인쇄 카드
  hooks/       저장소, 설정, 위치, 해시, 미디어 쿼리, 알림
  lib/         파일 내려받기·클립보드, 조사(을/를) 처리
```

### 주의해서 다룬 부분

- **좌표 순서**: 앱 안에서는 `[위도, 경도]`, GeoJSON은 `[경도, 위도]`, GPX는 `lat`·`lon` 속성입니다. 변환은 `domain/geojson.ts`, `domain/gpx.ts` 두 곳에서만 하고, 왕복 결과가 원본과 같은지 도메인 테스트와 스모크 테스트(내보낸 파일을 초기화 후 다시 가져와 거리 비교)로 확인합니다.
- **StrictMode**: 지도 생성 이펙트의 정리 함수에서 `map.remove()`를 부르고, 늦게 도착하는 폰트 이벤트가 지운 지도에 닿지 않게 막습니다.
- **크기 변경**: 지도 컨테이너를 ResizeObserver로 지켜보고 `invalidateSize`를 부릅니다.
- **마커를 빠르게 끌고 놓을 때**: 아이콘이 한 프레임 늦게 따라와 브라우저가 지도에 click을 보내는 경우가 있어, 끌기 직후의 지도 click은 무시합니다.
- **경유점과 장소 표식이 겹칠 때**: 코스가 장소를 지나면 경유점이 장소 표식과 같은 자리에 놓입니다. 경유점은 표식보다 위 층(pane)에 그려서 코스 수정 중에도 고르고 끌 수 있습니다.
- **여러 탭**: 같은 브라우저의 다른 탭에서 저장하면 `storage` 이벤트로 받아 와서, 한 탭이 다른 탭의 변경을 덮어쓰지 않습니다.
- **한꺼번에 바꾸는 작업의 되돌리기**: 가져오기·예시 지우기·전체 초기화를 되돌릴 때 작업 전 상태로 통째로 덮지 않고, 알림이 떠 있는 사이 새로 남기거나 고친 항목은 지킵니다.

## 데이터 저장 방식과 개인정보

- 장소·코스는 이 브라우저의 `localStorage`(보통 5MB 안팎)에 `toyz-offgrid:data` 키로, 지도 톤·마지막 화면 위치·탭은 `toyz-offgrid:settings` 키로 저장합니다. 둘 다 스키마 버전 필드가 있습니다.
- 저장된 데이터가 손상되면 앱은 빈 지도로 시작하고 알려 줍니다. 손상된 원본은 `toyz-offgrid:data:corrupt-backup`에 따로 남겨 둡니다. 저장 공간이 가득 차 쓰지 못할 때도 알려 줍니다.
- 서버가 없고 데이터를 어디로도 보내지 않습니다. 바깥으로 나가는 요청은 지도 타일(tile.openstreetmap.org)뿐입니다.
- 위치 정보는 "내 위치" 버튼을 눌렀을 때만 요청하고, 화면 표시와 거리 계산에만 쓰며 저장하지 않습니다.
- 공유 링크는 데이터가 주소 안에 그대로 들어 있습니다. 링크를 가진 사람은 누구나 내용을 볼 수 있으니 필요한 항목만 골라 공유하세요.

## 알려진 한계

- 코스는 경유점을 직선으로 잇습니다. 도로를 따라가는 길 찾기는 없고, 거리는 경유점 사이 직선 거리(haversine)의 합이라 실제 걷는 거리보다 조금 짧을 수 있습니다. 고도는 다루지 않습니다.
- 주소·상호 검색(지오코딩)은 없습니다. 외부 API 없이 브라우저 안에서 완결하기 위해서입니다.
- 지도 타일은 OpenStreetMap 공개 타일 서버를 씁니다. 네트워크가 없으면 타일 대신 옅은 격자만 보입니다(데이터와 기능은 그대로 동작합니다). 사용자가 많아지면 타일 이용 정책에 맞춰 별도 타일 서버로 옮겨야 합니다.
- 데이터는 기기마다 따로입니다. 다른 기기로 옮길 때는 GeoJSON 내보내기·가져오기나 공유 링크를 씁니다.
- 공유 링크는 코스가 길수록 길어집니다(예시 코스 1개와 경유 장소 5곳이 약 2천 자).
- GPX를 가져올 때 고도(ele)·시간(time)은 무시하고, GeoJSON의 면(Polygon) 도형은 가져오지 않습니다. 여러 구간(trkseg)으로 된 트랙은 한 코스로 이어 붙입니다.
- 원래 마켓플레이스 소개에는 Mapbox가 적혀 있었지만, API 키 없이 동작하도록 Leaflet과 OpenStreetMap으로 바꿨습니다.
