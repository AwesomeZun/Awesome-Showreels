# LAYR — 아이디어를 정리하는 AI 워크스페이스

흩어진 메모를 연결해 하나의 프로젝트로 만드는 노트 앱입니다. 메모를 적으면 비슷한 것끼리 묶어 프로젝트를 제안하고, 프로젝트 안의 메모를 **배경·문제 / 아이디어 / 할 일 / 참고 / 질문** 다섯 레이어로 나누고, 한 장짜리 브리프로 정리합니다.

LAYR의 'AI'는 모두 **브라우저 안에서 도는 로컬 알고리즘**입니다. 메모를 서버나 외부 AI 서비스로 보내지 않으며, 대형 언어 모델을 쓰지 않으므로 문장을 지어내지 않고 사용자가 쓴 문장을 고르고 묶기만 합니다. 화면 곳곳에 분석 근거(공통 키워드, 응집도, 유사도 점수, 레이어 판단 이유, 출처 메모)를 함께 보여 드립니다.

> toyz 마켓플레이스의 예시 프로젝트를 실제 앱으로 구현했습니다.

## 주요 기능

- **빠른 캡처** — 상단 입력창에 쓰고 `Enter`로 저장, `Shift+Enter`로 줄바꿈합니다(한글 조합 중 Enter는 저장하지 않습니다). 수정, 삭제(되돌리기), 고정, `#해시태그` 자동 인식, 간단한 마크다운(**굵게**, 목록, `- [ ]` 체크박스, 링크, `코드`)을 지원합니다.
- **작성 중 관련 메모 추천** — 입력을 잠시 멈추면 비슷한 메모 최대 5개를 유사도 점수와 겹치는 단어와 함께 보여 줍니다. 거의 같은 메모가 있으면 "기존 메모에 합치기"를 제안합니다.
- **중복 감지와 병합** — 코사인 유사도나 글자 겹침(Dice)이 0.72 이상인 메모 쌍을 찾아 합치기(되돌리기 가능) 또는 "중복 아님"을 고를 수 있습니다.
- **정리하기** — 인박스 메모를 유사도로 묶어 새 프로젝트 후보를 제안합니다. 묶음마다 자동 이름(상위 공통 키워드 조합), 포함 메모, 응집도, 묶인 근거를 보여 줍니다. 이름을 고치고 메모를 빼거나 다른 묶음으로 옮긴 뒤 수락하면 프로젝트가 됩니다. 기존 프로젝트와 가까운 새 메모는 "기존 프로젝트에 넣기"로 따로 제안합니다. 어디에도 맞지 않는 메모는 인박스에 남습니다. 묶음 기준(유사도 임계값)을 슬라이더로 바꿀 수 있습니다.
- **레이어 보드** — 프로젝트 메모를 문형(물음표, 묻는 어미, 제안하는 물음), 키워드, 체크박스, URL 등의 규칙 점수로 다섯 레이어에 자동 분류합니다. 손잡이를 끌어 레이어 사이를 옮기거나 순서를 바꿀 수 있고(마우스·터치), 키보드로도(`↑↓` 순서, `Shift+↑↓` 레이어) 옮길 수 있습니다. 직접 옮긴 메모는 "레이어 다시 분류"를 해도 건드리지 않습니다.
- **자동 브리프** — 목표 요약, 핵심 아이디어, 다음 할 일, 열린 질문으로 된 한 장짜리 문서를 만듭니다. 항목마다 출처 메모로 가는 링크(↗)가 있고, 편집·마크다운 복사·`.md` 내려받기를 제공합니다. 편집 중에 다른 탭이나 화면으로 가거나 새로고침해도 저장하지 않은 편집은 초안으로 보관했다가 되살리고, 취소한 편집은 알림의 되돌리기로 다시 불러올 수 있습니다.
- **연결 그래프** — 메모가 노드, 유사도가 간선입니다. 직접 구현한 force 레이아웃을 캔버스에 그리며, 연결 기준 슬라이더, 프로젝트별 색, 노드 끌기, 노드를 누르면 메모 열기, 연결이 많은 메모 목록을 제공합니다. 키보드로는 그래프에 포커스를 두고 방향키로 노드를 고른 뒤 `Enter`로 엽니다.
- **전체 검색** — 글자가 그대로 들어간 메모를 강조해 먼저 보여 주고, 아래에 검색어는 없지만 뜻이 가까운 메모(코사인 유사도, 겹치는 단어)를 제시합니다. 한 단어로 찾아도 결과가 나오도록 글자 일치 메모에 함께 나온 말로 검색어를 넓히며(Rocchio 질의 확장), 넓힌 말을 화면에 그대로 보여 드립니다. 태그·위치(인박스/프로젝트) 필터를 주소에 반영하므로 새로고침해도 유지됩니다.
- **프로젝트 진행 요약** — 프로젝트 카드마다 레이어 구성 막대와 체크박스 완료 비율을 보여 줍니다.
- **커맨드 팔레트와 단축키** — `⌘K`/`Ctrl+K` 명령 팔레트(화면 이동, 프로젝트 열기, 메모 찾기), `/` 빠른 캡처로 이동, 메모 카드에서 `P` 고정.
- **데이터** — JSON 내보내기·가져오기(합치기/바꾸기), 예시 데이터 지우기·다시 넣기, 전체 초기화(확인 후, 되돌리기 가능). 가져오기는 먼저 저장해 보고 저장 공간이 모자라면 기존 데이터를 그대로 둔 채 거부합니다.
- **첫 실행 예시** — 반려식물 물주기 앱, 동네 러닝 크루, 사이드 프로젝트 팟캐스트 세 주제와 잡동사니가 섞인 메모 32개가 들어 있어 정리하기를 바로 체험할 수 있습니다. 인물·서비스 이름은 모두 가상입니다.

## 사용 방법

1. 인박스 위 입력창에 생각을 적고 `Enter`를 누릅니다. 같은 주제에는 같은 `#태그`를 달면 더 잘 묶입니다.
2. **정리하기**에서 제안된 묶음을 확인하고, 이름을 고치거나 메모를 뺀 뒤 **수락하고 프로젝트 만들기**를 누릅니다.
3. 프로젝트의 **레이어** 탭에서 메모를 끌어 알맞은 레이어로 옮깁니다.
4. **브리프** 탭에서 한 장짜리 요약을 확인하고, 필요하면 편집한 뒤 마크다운으로 복사하거나 내려받습니다.
5. **그래프**와 **검색**으로 메모 사이의 연결을 살펴봅니다.

## 실행·빌드·테스트

```sh
npm install --no-audit --no-fund
npm run dev            # 개발 서버
npm run build          # 타입 검사 + 프로덕션 빌드(dist/)
npm run lint           # oxlint
npm run test:engine                   # 분석 엔진 검증(Node 22.18 이상, 타입 스트리핑)
PORT=4309 npm run test:smoke          # 빌드본을 헤드리스 Chrome으로 점검
```

스모크 테스트는 첫 화면, 빠른 캡처와 마크다운, 관련 메모·중복 경고, 수정·고정·삭제·되돌리기, 새로고침 뒤 유지, 중복 병합, 정리하기(이름 수정·메모 빼기·옮기기·수락), 레이어 드래그와 키보드 이동, 브리프 편집·복사·내려받기, 그래프, 검색과 필터, 커맨드 팔레트, JSON 내보내기·초기화·가져오기, 메모 500개 성능, 모바일 가로 넘침과 탭 이동을 확인합니다. QA에서 찾아 고친 문제(모두 수락 되돌리기 때 인박스 메모 삭제, 대문자 태그 필터, 건너뛰기 링크, 그래프 키보드 조작, 팔레트·데이터 창 포커스, 긴 메모 잘림, 여러 탭 덮어쓰기, 저장 실패 안내, 가져오기 프로젝트 id 충돌, 기존 프로젝트 제안 근거, 한 단어 검색어의 의미 결과, 아주 긴 메모가 있을 때 담기 지연)는 `회귀:` 시나리오로 따로 확인합니다. 외부로 나가는 네트워크 요청이 하나라도 있으면 실패로 처리합니다.

## 분석 방식

| 단계 | 방법 |
| --- | --- |
| 토큰화 | 한국어는 조사(은·는·을·를·에서·으로…)와 흔한 어미를 규칙으로 떼고, 영어는 복수형·진행형을 줄입니다. 불용어를 거르고, 조사 제거가 어긋나도 부분 일치를 잡도록 한글 2-gram을 약한 가중치로 섞습니다. '고양이'의 '이', '회의'의 '의'처럼 명사 끝 글자와 겹치는 조사는 같은 말이 코퍼스에 따로 나타날 때만 뗍니다. |
| 벡터 | TF-IDF(로그 TF, 스무딩한 IDF). 해시태그는 한 번 더 세고, 코퍼스에 한 번만 나오는 말은 가중치를 낮춥니다. L2 정규화한 희소 벡터입니다. |
| 유사도 | 코사인 유사도. 관련 메모, 검색, 그래프, 중복 감지에 씁니다. |
| 검색 | 글자 일치(부분 문자열)와 의미 검색을 함께 합니다. 의미 검색은 Rocchio 질의 확장(q' = 1·검색어 + 0.75·글자 일치 메모의 중심 벡터)으로 넓힌 질의와 코사인이 0.06 이상인 메모를 찾되, 0.10 미만이면 겹치는 말이 두 개 이상일 때만 인정합니다. 글자 일치가 없으면 처음 유사도 상위 메모 3개(0.10 이상)로 넓힙니다(의사 적합성 피드백). 예시 메모의 단어 159개로 찾아 보면 같은 주제 메모의 81%를 찾고 다른 주제는 섞이지 않습니다. |
| 군집 | ① 평균 연결 계층 군집(Lance–Williams 갱신)으로 확실한 핵을 만들고 ② 중심 벡터가 가까운 핵을 합친 뒤 ③ 남은 메모는 한 묶음에만 뚜렷하게 가까울 때 붙입니다. 공유 단어가 하나뿐인 쌍은 유사도를 절반으로 깎아 우연한 짝이 묶이지 않게 합니다. |
| 레이어 | 문형·키워드·체크박스·URL 규칙에 점수를 매겨 가장 높은 레이어를 고릅니다. 판단 이유를 메모 자세히 보기에서 보여 줍니다. |
| 브리프 | 프로젝트 중심 벡터에 가까운 문장을 고르는 추출 요약입니다. |
| 그래프 | 반발력(거리에 반비례)·간선 스프링·중심 인력·감쇠를 직접 계산하는 force 레이아웃입니다. 노드마다 가장 가까운 6개 간선만 남겨 메모가 많아도 읽을 수 있게 합니다. |

메모 500개 기준으로 색인은 수 ms, 군집은 수십 ms 안에 끝납니다(`tests/engine.test.mjs`에서 측정).

## 기술 구성

- Vite 8, React 19, TypeScript 6(strict), oxlint, playwright-core(스모크 테스트)
- 추가 런타임 의존성 없음. 분석 엔진, 마크다운 파서, force 레이아웃, 드래그 앤 드롭을 모두 직접 구현했습니다.
- 본문 글꼴 Pretendard Variable(자체 호스팅). 외부 CDN·폰트 링크가 없습니다.
- 해시 라우팅(`#/`, `#/organize`, `#/projects`, `#/p/<id>`, `#/p/<id>/brief`, `#/graph`, `#/search?q=`)이라 서버 설정 없이 새로고침할 수 있습니다.

```
src/
  engine/   토크나이저, TF-IDF, 군집, 정리 계획, 레이어 분류, 브리프, 중복, 검색, 마크다운, force 레이아웃(순수 함수)
  state/    리듀서, 저장·복구, 컨텍스트, 동작(되돌리기), 해시 라우터
  components/ 캡처 바, 메모 카드, 레이어 보드, 브리프, 메모 시트, 데이터 창, 팔레트 등
  views/    인박스, 정리하기, 프로젝트 목록, 프로젝트, 그래프, 검색
```

## 데이터 저장과 개인정보

- 모든 데이터는 이 브라우저의 `localStorage`(키 `toyz-layr:state`, 스키마 버전 1)에만 저장됩니다. 서버가 없고, 앱은 외부로 네트워크 요청을 보내지 않습니다.
- 같은 브라우저에서 탭을 여러 개 열면, 한 탭에서 저장한 내용을 다른 탭이 받아 와서 오래된 탭이 새 내용을 덮어쓰지 않습니다.
- 저장에 실패하면(용량 초과, 사생활 보호 모드) 화면 위에 경고가 계속 떠 있고, JSON 내보내기로 바로 백업할 수 있습니다.
- 메모 하나는 최대 50,000자입니다. 입력창·편집기·병합·불러오기가 모두 같은 한도를 씁니다. 목록 카드에는 앞부분 800자까지만 그리고 "전체 N자 보기"로 자세히 보기를 엽니다. 아주 긴 글을 목록에 통째로 그리면 화면을 다시 배치할 때마다 멈추기 때문입니다(저장되는 본문은 그대로입니다).
- 저장된 데이터가 손상되면 원본을 `toyz-layr:state:corrupt-backup`에 보관하고 예시 메모로 다시 시작합니다. 보관한 원본은 데이터 창에서 내려받거나 지울 수 있습니다.
- 가져오기 파일은 필드마다 검사해 잘못된 항목을 버리고, 없는 프로젝트를 가리키는 메모는 인박스로 돌려보냅니다.
- 다른 기기로 옮기려면 JSON 내보내기·가져오기를 이용해 주세요.

## 알려진 한계

- 토크나이저는 규칙 기반입니다. 불규칙 활용, 복합명사 분해, 동음이의어(예: '노래졌다'와 '노래')는 구분하지 못합니다. 같은 주제에 같은 `#태그`를 달면 결과가 안정됩니다.
- 의미 검색은 글자 일치 메모를 근거로 넓히므로, 한 주제의 메모가 모두 검색어를 담고 있으면(예시에서 '러닝') 더 보여 줄 메모가 없어 의미 결과가 비고, 화면에 그 이유를 알려 드립니다. 띄어쓰기 없이 붙여 쓴 검색어(예: '물주기알림')는 글자 일치도 의미 결과도 잘 찾지 못하니 띄어서 찾아 주세요.
- 레이어 분류도 규칙 기반이라 반어나 여러 성격이 섞인 문장에서 틀릴 수 있습니다. 끌어서 옮기면 그 판단이 우선합니다.
- 브리프는 추출 요약이라 문장을 새로 다듬지 않습니다. 필요하면 직접 편집해 주세요(편집본은 저장되고 자동 생성본으로 되돌릴 수 있습니다).
- 그래프는 확대·이동(줌·팬)을 지원하지 않습니다. 노드 끌기와 프로젝트 필터로 살펴봐 주세요.
- 레이어 사이 드래그는 한 프로젝트 안에서만 됩니다. 다른 프로젝트로 옮기려면 메모 자세히 보기의 위치 선택을 이용해 주세요.
- `localStorage` 용량(보통 5MB 안팎)을 넘으면 더 저장하지 못합니다. 화면 위 경고가 보이면 JSON으로 내보내 두고 메모를 정리해 주세요.
- 여러 탭에서 같은 순간(0.1초 안)에 함께 고치면 한쪽 변경이 다른 쪽 변경으로 바뀔 수 있습니다.
- 레이어 자동 분류 규칙은 한국어 문형을 중심으로 만들었고, 영어 메모는 기본적인 문형(명령문, 의문문, idea·problem 같은 키워드)만 봅니다.
