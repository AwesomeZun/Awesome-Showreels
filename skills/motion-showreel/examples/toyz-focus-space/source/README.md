# FOCUS SPACE

> 해야 할 일 하나에 집중하는 작은 방

문을 닫으면 조용해지는 작은 방입니다. 화면에는 지금 할 일 하나와 시간만 남습니다.
뽀모도로 타이머, 할 일 목록, 앰비언트 사운드, 주간 기록을 담은 미니멀 생산성 앱이며, 설치해서 오프라인으로도 쓸 수 있는 PWA입니다.

toyz 마켓플레이스의 예시 프로젝트 FOCUS SPACE를 실제 앱으로 구현했습니다.

## 주요 기능

**타이머**
- 집중·짧은 휴식·긴 휴식(기본 25·5·15분, 설정에서 변경), N회 집중 뒤 긴 휴식
- 시작·일시정지·건너뛰기·초기화·5분 더, 건너뛰기와 초기화는 토스트에서 되돌릴 수 있습니다
- 휴식 자동 시작, 집중 자동 시작(각각 켜고 끌 수 있습니다)
- 남은 시간을 `Date` 기준으로 계산해 백그라운드 탭·절전·새로고침 뒤에도 정확합니다. 진행 중이던 타이머는 새로고침해도 그대로 이어집니다
- 문서 제목에 남은 시간, 아치형 "문" 안의 큰 크롬 링으로 진행을 보여 줍니다

**지금 하나**
- 할 일을 ◎ 버튼으로 고정하면 타이머 가운데에 놓이고, 끝낸 세션이 그 할 일에 기록됩니다
- 타이머 가운데의 제목을 누르면 바로 바꾸거나, 새로 적어서 고를 수 있습니다. 대상 없이도 시작할 수 있습니다

**할 일**
- 추가·수정·삭제(되돌리기)·완료, 오늘/나중에 목록, 완료 항목 접기
- 예상 집중 횟수(빈 점)와 실제 횟수(채운 점, 자동 집계)
- 순서 바꾸기: 손잡이를 끌기(마우스·터치), 손잡이에서 ↑↓ 키, 또는 메뉴의 위로/아래로

**종료 알림**
- Web Audio로 합성한 알림음 3종(종소리·나무 두드림·디지털 비프)과 음량. 끝나기 직전에 AudioContext 시간축에 미리 예약해 백그라운드 탭에서도 제때 울립니다
- 시스템 알림(Notification API): 설정에서 켜면 권한을 요청하고, 거부되면 스위치는 꺼진 채 소리·탭 제목 깜빡임으로 대신 알린다고 안내합니다. 알림을 누르면 열려 있는 FOCUS SPACE 창으로 돌아갑니다
- 탭 제목 깜빡임
- 오래 숨겨 둔 탭에서는 브라우저가 창의 타이머를 1분에 한 번으로 묶기 때문에, 작은 전용 워커가 1초마다 엔진을 깨워 종료 알림과 탭 제목이 늦지 않게 합니다

**앰비언트 사운드 믹서**(녹음 파일 없이 전부 합성)
- 빗소리, 브라운 노이즈, 바람, 모닥불, 카페 웅성임 5종과 채널별 음량
- 집중 중에만 재생 옵션, 부드러운 페이드 인·아웃

**주간 기록**
- 오늘 집중 시간·완료 횟수·목표 달성률, 연속 기록(최고 기록 포함), 이번 주 합계
- 최근 7일 막대 차트와 최근 12주 히트맵(SVG, 마우스·키보드로 값 보기, 표로 보기). 키보드로는 차트마다 Tab 한 번에 들어가 화살표 키로 칸을 옮겨 다닙니다
- 세션 로그(언제, 무엇에, 몇 분, 중단 여부), 세션 직접 추가와 삭제(되돌리기)
- 할 일별 누적 시간

**집중 모드와 단축키**
- 집중 모드: 전체 화면(Fullscreen API)과 방해 요소 숨김. 집중 중에는 모드를 켜지 않아도 주변 패널이 흐려집니다
- 화면 꺼짐 방지(Screen Wake Lock, 지원하지 않는 브라우저에서는 생략)
- 단축키: `Space` 시작·정지, `S` 건너뛰기, `N` 새 할 일, `F` 집중 모드, `M` 음소거, `Esc` 집중 모드 끝내기(한글 자판에서도 동작)

**그 밖에**
- 생각 서랍: 집중하다 떠오른 생각을 적어 두고 나중에 할 일로 옮깁니다
- 설정: 시간, 하루 목표, 알림, 소리, 테마(세이지 라이트·딥 그린 다크·시스템), 주 시작 요일, JSON 내보내기·가져오기, 예시 데이터 지우기, 전체 초기화
- PWA: 오프라인 동작, 설치(매니페스트, 192·512·maskable 아이콘), 새 버전 알림

## 사용 방법

1. 처음 열면 예시 할 일과 10주치 예시 기록이 들어 있습니다. 설정 → 데이터 → "예시 지우기"로 한 번에 지울 수 있습니다.
2. 오른쪽(모바일은 "할 일" 탭) 목록에서 오늘 할 일을 적고 ◎를 눌러 "지금 하나"로 고릅니다.
3. `시작`(또는 `Space`)을 누르면 집중이 시작되고 주변이 조용해집니다. 더 조용히 하고 싶으면 `F`로 집중 모드를 켭니다.
4. 끝나면 알림음과 함께 휴식으로 넘어갑니다. 기록 화면에서 하루와 한 주를 돌아봅니다.

## 실행·빌드·테스트

Node.js 20.19 이상이 필요합니다.

```sh
npm install
npm run dev          # 개발 서버
npm run build        # 타입 검사 + 프로덕션 빌드(dist/, 서비스 워커 포함)
npm run preview      # 빌드 결과 미리보기
npm run lint         # oxlint
npm run test:unit    # 도메인 순수 함수 테스트(node:test, Asia/Seoul 시간대 고정)
PORT=4315 npm run test:smoke   # 빌드 결과로 헤드리스 Chrome 사용자 흐름 테스트
npm run icons        # public/favicon.svg와 PWA 아이콘 PNG 다시 만들기
PORT=4315 node tests/shots.mjs # 디자인 점검용 스크린샷(tests/artifacts/shots/)
```

스모크 테스트는 `page.clock`으로 시계를 조작해 25분 경과, 일시정지 누적, 새로고침 복원, 자정 넘김, 자동 시작을 확인하고,
서비스 워커가 최신 빌드를 내주는지, 오프라인(`context.setOffline`)에서 앱이 열리는지, 새 버전 알림이 뜨고 적용되는지까지 확인합니다.
서비스 워커 업데이트 시나리오는 배포를 흉내 내려고 테스트 중에 `dist/sw.js`의 버전 문자열을 잠시 바꿨다가 되돌립니다.

## 기술 구성

- Vite 8, React 19, TypeScript 6(strict), oxlint, playwright-core(테스트)
- 추가 의존성 없음. 서비스 워커·앰비언트 합성·차트·드래그 정렬을 모두 직접 구현했습니다
- 글꼴: Pretendard Variable(자체 호스팅, 동적 서브셋)
- 구조
  - `src/domain/` 순수 함수: 타이머(`timer.ts`), 집계(`stats.ts`), 할 일(`tasks.ts`), 저장값 검증(`sanitize.ts`), 예시 데이터
  - `src/state/` 의존성 없는 작은 스토어와 동작(action), 저장
  - `src/audio/` AudioContext, 알림음 합성, 앰비언트 엔진
  - `src/platform/` 알림, 탭 제목, 전체 화면·Wake Lock, 서비스 워커 등록, 숨긴 탭을 깨우는 워커(`ticker.ts`)
  - `src/hooks/` 엔진(시계 진행·알림·앰비언트·테마), 단축키, 해시 라우팅
  - `sw/sw.js` 서비스 워커 템플릿. `vite.config.ts`의 작은 플러그인이 빌드 버전과 미리 캐시할 파일 목록을 채워 `dist/sw.js`로 내보냅니다
- 서비스 워커 전략: 페이지는 네트워크 우선(온라인이면 항상 최신 빌드), 해시가 붙은 파일과 아이콘은 캐시 우선. 앱 화면 글자에 필요한 글꼴 조각 29개는 설치할 때 미리 담고, 나머지 조각은 쓰일 때 담습니다. 새 워커는 기다렸다가 사용자가 "새로고침"을 누르면 적용되고, 켜질 때 이번 빌드에 없는 옛 해시 파일을 런타임 캐시에서 지워 배포가 거듭되어도 캐시가 쌓이지 않습니다
- vite-plugin-pwa는 Vite 8을 지원하지만, 의존성을 늘리지 않고 업데이트 흐름과 글꼴 캐시를 세밀하게 다루려고 서비스 워커를 직접 작성했습니다
- 라우팅: 해시(`#/`, `#/tasks`, `#/log`, `#/settings`). 서버 rewrite 설정이 필요 없습니다

### 시간과 기록 규칙

- 타이머는 "언제 시작했는가"만 저장하고 남은 시간을 매번 계산합니다. 일시정지할 때마다 실행 구간을 닫아 누적합니다
- 단계가 끝난 시각은 감지한 시각이 아니라 예정 종료 시각으로 기록합니다. 자동 시작이 켜져 있으면 다음 단계도 그 시각부터 이어집니다. 다만 절전 등으로 다음 단계마저 끝났을 만큼 오래 비웠다면, 자리에 없던 시간을 기록하지 않도록 대기 상태에서 멈춥니다
- 1분 이상 집중하다 건너뛰거나 초기화하면 "중단" 세션으로 남깁니다
- 자정을 넘긴 세션: 집중 시간은 실제 구간을 자정에서 잘라 날짜별로 나눠 더하고, 완료 횟수와 세션 로그는 끝난 날짜에 적습니다(정확히 0시에 끝나면 전날). 예: 23:50~00:15 → 전날 10분, 다음 날 15분·1회
- 연속 기록은 1분 이상 집중한 날이 이어진 일수입니다. 오늘 아직 기록이 없어도 어제까지 이어졌다면 끊긴 것으로 보지 않습니다

## 데이터 저장 방식과 개인정보

- 모든 데이터는 이 브라우저의 `localStorage`에만 저장합니다. 서버로 보내지 않고, 외부 네트워크 요청도 하지 않습니다
- 키: `toyz-focus-space:settings`, `:tasks`, `:sessions`, `:timer`, `:memos`, `:meta`. 각 값은 `{ v: 스키마 버전, data }` 형태입니다
- 저장값이 손상되었거나 형식이 달라도 앱이 죽지 않도록 읽을 때 검증하고, 알 수 없는 값은 기본값으로 채웁니다
- 같은 앱을 두 탭에서 열면 `storage` 이벤트로 상태를 맞추고, 같은 세션이 두 번 기록되지 않게 합니다
- 설정 → 데이터에서 JSON으로 내보내고 가져올 수 있습니다(가져오기 전 요약을 보여 주고 확인을 받습니다)
- 가져오기는 10MB 이하 파일만 읽습니다. 모든 조각을 저장하는 데 성공해야 반영하고, 브라우저 저장 공간이 모자라면 이미 쓴 조각을 되돌린 뒤 "가져오지 못했어요"라고 알립니다(일부만 저장되어 섞이지 않습니다)
- 평소에 저장이 실패하면(저장 공간 부족, 저장소 차단) 경고 토스트로 JSON 백업을 권합니다

## 알려진 한계

- 있으면 좋은 기능 중 "세션 태그"는 구현하지 않았습니다(데이터 필드만 자리 잡아 두었습니다). "생각 서랍"은 구현했습니다
- 브라우저 자동 재생 정책 때문에, 페이지를 연 뒤 한 번도 누르거나 키를 치지 않았다면 알림음과 앰비언트가 나오지 않습니다. 이때도 시스템 알림과 탭 제목 깜빡임은 동작합니다
- 오래 숨겨 둔 탭의 타이머 제한은 전용 워커로 피하지만, 브라우저가 탭 자체를 얼리면(메모리·배터리 절약, 노트북 절전) 그동안에는 아무 코드도 돌지 않습니다. 이때도 기록되는 종료 시각은 예정 시각으로 정확하고, 알림은 탭이 다시 깨어날 때 울립니다
- 절전 등으로 다음 단계가 끝날 만큼 오래 비웠다면 자동 시작을 이어 가지 않고 그 단계의 대기 상태에서 멈춥니다(자리에 없던 시간을 집중으로 기록하지 않기 위해서입니다)
- iPhone Safari는 전체 화면 API가 없어 집중 모드가 방해 요소 숨김만 합니다. iOS의 시스템 알림은 홈 화면에 추가한 앱(iOS 16.4 이상)에서만 됩니다
- Screen Wake Lock을 지원하지 않는 브라우저에서는 화면 꺼짐 방지를 건너뜁니다
- 오프라인에서 처음 입력한 드문 한글 글자는 해당 글꼴 조각이 캐시에 없으면 시스템 글꼴로 보일 수 있습니다
- 기기 간 동기화는 없습니다. JSON 내보내기·가져오기로 옮겨 주세요
