# Motion Kit — 클릭 한 번에 작은 즐거움을

버튼과 카드에 바로 얹을 수 있는 인터랙션 27종을 모아 둔 진열장입니다. 만져 보고, 값을 조절하고, 보이는 코드를 그대로 가져가세요. 모든 데모는 화면에 보이는 바닐라 HTML·CSS·JS 스니펫을 iframe에 그대로 넣어 실행하므로, **보이는 코드가 곧 실행되는 코드**입니다.

toyz 마켓플레이스의 예시 프로젝트를 실제 앱으로 구현했습니다.

## 주요 기능

- **인터랙션 27종**
  - 버튼 8종: 마그네틱, 리플, 컨페티 버스트, 길게 눌러 확인, 젤리 프레스, 샤인 스윕, 로딩 → 성공 모핑, 좋아요 하트 파티클
  - 카드 6종: 3D 틸트와 글레어, 홀로그래픽 포일, 플립, 스택 스와이프, 스포트라이트 테두리, 스프링 드래그
  - 입력·토글 5종: 토글 모핑, 체크 그리기, 플로팅 라벨, 오류 흔들림, 세그먼트 슬라이드
  - 텍스트·숫자 4종: 텍스트 스크램블, 카운터 롤, 글자별 등장, 타자기
  - 피드백 4종: 토스트 스택, 스켈레톤 시머, 툴팁 팝, 벨 흔들림 배지
- **라이브 데모와 조절 패널**: 항목마다 2~4개의 파라미터(지속 시간, 강도, 이징, 색, 문구 등)를 바꾸면 코드와 데모 무대에 곧바로 반영돼요. 다시 재생 버튼, 밝은·어두운 무대 전환, "새 창에서 단독 실행"을 제공합니다.
- **코드 보기와 복사**: HTML·CSS·JS·전체 파일 탭, 의존성 없는 구문 강조, 복사·내려받기. 조절한 값이 코드에 그대로 들어갑니다. JS는 즉시 실행 함수로 감싸 두어, 여러 인터랙션을 한 페이지의 서로 다른 `<script>`에 붙여도 변수 이름이 부딪히지 않고 페이지의 전역 변수도 건드리지 않습니다.
- **이징 놀이터**: cubic-bezier 곡선 편집기(핸들 드래그·방향키, 프리셋, 값·CSS 한 줄 복사), 스프링 시뮬레이터(질량·강성·감쇠·초기 속도 → 해석해 곡선 → CSS `linear()` 문자열 생성·복사, 근사 오차와 브라우저 지원 여부 표시), 네 곡선을 나란히 달리는 비교 미리보기(같은 시간 간격의 잔상 표시), 내 이징 저장.
- **검색·필터**: 이름·영어 이름·태그·한글 초성(예: `ㅁㄱㄴㅌ`) 검색, 분류 필터, 즐겨찾기만 보기, 최근 본 항목. `/` 키로 검색창에 바로 갈 수 있어요.
- **킷 내려받기**: 즐겨찾기나 고른 항목을 묶어 단독 데모 HTML 한 장, `motion-kit.css`, `motion-kit.js`를 따로 또는 ZIP 하나로 내려받습니다. 킷 데모는 페이지 안에서 바로 미리 볼 수 있어요.
- **모션 줄이기**: 상단의 전역 토글은 기기 설정을 기본값으로 따르고, 직접 켜거나 끌 수 있어요. 모든 스니펫에 `prefers-reduced-motion` 대체가 들어 있습니다.
- **상세 보기와 개별 링크**: `#/i/<id>?파라미터` 형식의 해시 주소로 지금 설정을 그대로 공유할 수 있어요. 같은 항목을 보는 중에 링크를 열어도 링크 값이 적용되고, 내가 조절해 둔 값을 덮어쓰면 "내 설정으로 되돌리기" 알림이 떠요.
- **접근성·터치 메모**: 항목마다 키보드·스크린 리더 대응과 터치 기기에서의 대체 동작을 적어 두었습니다.

## 사용 방법

1. 첫 화면의 진열장에서 카드를 만져 봅니다. 하트로 즐겨찾기하고, "조절·코드 보기"로 상세 화면에 들어갑니다.
2. 오른쪽 조절 패널에서 값을 바꾸고, 아래 코드 탭에서 HTML·CSS·JS를 복사하거나 "전체 파일"을 복사해 빈 `.html` 파일에 붙여 넣으면 그대로 동작합니다.
3. 이징 놀이터에서 곡선을 만들어 복사하거나 "내 이징"에 저장합니다.
4. 킷 만들기에서 가져갈 항목을 고르고 파일을 내려받습니다. `motion-kit.css`를 `<head>`에, `motion-kit.js`를 `defer`로 넣고, 데모 HTML에서 필요한 마크업을 복사해 쓰면 됩니다.
5. 설정에서 모션·무대를 바꾸거나, JSON으로 내보내기·가져오기, 예시 데이터 지우기, 전체 초기화를 할 수 있어요.

## 실행·빌드·테스트

Node.js 22.18 이상을 권장합니다(단위·스니펫 검증 스크립트가 TypeScript 도메인 모듈을 Node로 바로 불러옵니다).

```sh
npm install --no-audit --no-fund
npm run dev             # 개발 서버
npm run build           # 타입 검사 + 프로덕션 빌드(dist/)
npm run lint            # oxlint

npm run test:unit       # 도메인 로직 검증(linear() 유효성·정확도, 파서, 저장소 방어, ZIP, 구문 강조 등)
npm run test:snippets   # 27종 스니펫을 빈 HTML 파일에 붙여 헤드리스 Chrome에서 실제 조작 검증
PORT=4308 npm run test:smoke   # 빌드본으로 사용자 흐름 22개 시나리오 검증(먼저 npm run build)
```

스모크 테스트는 `tests/artifacts/`에 데스크톱·모바일 스크린샷을 남깁니다. 헤드리스 Chrome은 `playwright-core`의 `channel: 'chrome'`으로 실행하므로 이 기기에 Chrome이 설치되어 있어야 합니다(`CHROME_PATH`로 직접 지정할 수도 있어요).

## 기술 구성

- Vite 8 + React 19 + TypeScript 6(strict), oxlint, playwright-core(테스트 전용)
- 본문 서체: Pretendard Variable(자체 호스팅)
- 런타임 의존성은 React와 Pretendard뿐입니다. 구문 강조기, 스프링 해석해와 `linear()` 생성기, ZIP 작성기(STORE 방식)는 직접 구현했습니다.
- 구조
  - `src/domain/` 순수 함수: 인터랙션 정의(`interactions/`), 파라미터 검증, 스니펫 조립, 이징 계산, 검색, 킷·ZIP 생성, 저장소 스키마, 라우팅
  - `src/components/` 데모 무대(`DemoFrame`), 조절 패널, 코드 보기, 히어로 매듭(캔버스) 등
  - `src/lib/knot.ts` 첫 화면의 홀로그래픽 리본 매듭 그리기: 세잎 매듭을 따라 비틀린 띠를 만들고, 조각마다 면의 방향으로 크롬 반사와 홀로 팔레트 색을 정해 멀리 있는 조각부터 칠합니다. 화면 밖에 있거나 모션 줄이기일 때는 멈춘 그림으로 둡니다.
  - `src/pages/` 진열장, 상세, 이징 놀이터, 킷 만들기, 설정
- 화면 디자인: 일렉트릭 블루 바탕에 홀로그래픽 포인트, 라일락·주황 보조색을 씁니다. 제목은 굵은 웨이트와 좁은 자간, 보조 라벨은 모노 대문자로 두고, 한글이 섞인 작은 라벨은 본문 서체로 씁니다. 모바일(760px 이하)에서는 주요 메뉴가 엄지가 닿는 화면 아래에 붙습니다.
- 데모 무대는 스니펫으로 만든 단독 문서를 `iframe srcdoc`으로 실행합니다. 화면 근처(위아래 400px)에 올 때만 iframe을 만들고, 멀어지면 내려 메모리를 돌려줍니다. 보이지 않는 동안에는 IntersectionObserver로 감지해 문서 안의 애니메이션·`requestAnimationFrame`·타이머를 멈춥니다. 파라미터가 바뀌면 새 문서를 뒤에서 불러온 뒤 바꿔 끼워 깜빡임이 없습니다.
- 전역 모션 설정을 강제로 켜거나 끌 때만, 데모 무대에서 스니펫의 `(prefers-reduced-motion: reduce)` 조건을 `all`/`not all`로 바꿔 실행합니다. 화면에 보이는 코드와 복사되는 코드는 바뀌지 않습니다.

## 데이터 저장 방식과 개인정보

- 즐겨찾기, 최근 본 항목, 조절한 파라미터(기본값과 다른 값만), 킷 선택, 내 이징, 모션·무대 설정을 브라우저 `localStorage`의 `toyz-motion-kit:state` 키 하나에 저장합니다(스키마 버전 필드 포함).
- 저장된 값이 손상되었거나 알 수 없는 값이 들어 있으면 검증 단계에서 걸러 내고, 읽을 수 없으면 처음 상태로 시작하며 안내합니다.
- 서버나 외부 서비스로 보내는 데이터는 없습니다. 외부 네트워크 요청도 하지 않습니다.
- JSON 가져오기는 2MB 이하 파일만 받습니다(내보낸 파일은 보통 수십 KB입니다). 가져온 값도 모두 같은 검증을 거치고, 가져온 뒤 되돌리기 알림으로 이전 상태로 돌아갈 수 있어요.
- 첫 실행에는 예시 즐겨찾기 3개와 예시 이징 2개가 들어 있고, 설정에서 "예시 데이터 지우기"로 지울 수 있습니다.

## 알려진 한계

- 스프링 `linear()` 문자열은 CSS Easing Level 2를 지원하는 브라우저(Chrome·Edge 113+, Safari 17.2+, Firefox 112+)에서 동작합니다. 스니펫에서 스프링 이징을 고르면 지원하지 않는 브라우저용 `cubic-bezier` 대체 규칙을 함께 넣습니다.
- 10초 안에 멈추지 않는 스프링(감쇠가 아주 약한 경우)은 끝부분을 잘라 마지막에 1로 건너뛰며, 화면에 경고를 보여 줍니다. `linear()` 점 수는 160개로 제한해 긴 진동에서는 근사 오차가 커질 수 있고, 오차 값을 함께 표시합니다.
- 화면 밖으로 멀리 스크롤했다가 돌아온 데모는 처음부터 다시 실행됩니다(메모리를 아끼기 위해 내렸다가 다시 불러오기 때문입니다).
- 3D 틸트·홀로그래픽 포일·스포트라이트처럼 hover에 기대는 효과는 터치 기기에서 손가락을 끄는 동안 반응하거나 대체 애니메이션을 보여 주며, 기기 기울기 센서는 쓰지 않습니다.
- 스니펫의 클래스 이름은 모두 `mk-` 접두사로 겹치지 않게 지었지만, 기존 페이지에 같은 이름의 스타일이 있으면 충돌할 수 있습니다.
