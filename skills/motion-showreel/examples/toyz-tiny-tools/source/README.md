# tiny.tools

> 매일 쓰는 개발 도구, 필요한 만큼만.

JSON 정리, 컬러 변환, 텍스트 비교부터 Base64·URL·JWT·해시·정규식·타임스탬프까지 14가지 개발 도구를 한곳에 모은 웹앱입니다.
**모든 처리는 브라우저 안에서만 이뤄지고**, 입력한 텍스트·토큰·파일은 어떤 서버로도 보내지 않습니다.

toyz 마켓플레이스의 예시 프로젝트를 실제 앱으로 구현했습니다.

## 주요 기능

| 번호 | 도구 | 할 수 있는 일 |
| --- | --- | --- |
| 01 | JSON | 들여쓰기(2칸·4칸·탭) 정리, 압축, 검증(오류 줄·열 표시와 주변 코드, 오류 위치로 이동), 키 정렬, 트리 보기(접기·펼치기, 경로 복사), `a.b[0].c` 경로 조회, TypeScript 타입 생성, 배열 → CSV. 1MB 입력도 멈추지 않습니다. |
| 02 | 컬러 | HEX·RGB·HSL·HWB·OKLCH 상호 변환(직접 구현), HSV 색 선택기와 알파, WCAG 대비(AA·AAA, 본문·큰 글자), OKLCH 명도 기준 50~950 팔레트, 보색·유사·삼각·분할 보색·사각 조화 색, CSS 변수 복사, 최근 색 기록 |
| 03 | 텍스트 비교 | Myers 알고리즘(선형 공간) 줄 단위 diff, 줄 안 단어·글자 강조, 나란히·통합 보기, 공백·대소문자 무시, 추가·삭제 통계, 변경 없는 구간 접기, unified patch 복사·다운로드 |
| 04 | Base64 | UTF-8 안전 인코딩·디코딩(한글·이모지), URL-safe, 파일 → data URI, 바이너리 디코딩 결과 파일로 받기 |
| 05 | URL | 퍼센트 인코딩·디코딩(값 하나·주소 전체, `+`를 공백으로), 주소 구성 요소와 쿼리 파라미터 표 |
| 06 | JWT | 헤더·페이로드·서명 분리, 표준 클레임 설명, 만료(exp)·유효 시작(nbf) 판정. **서명은 검증하지 않는다고 화면에 명시합니다.** |
| 07 | 해시 | SHA-1·256·384·512(SubtleCrypto), HMAC, 파일 해시, 기대값 비교 |
| 08 | 정규식 | 플래그 토글, 일치 강조, 캡처 그룹 표(이름 있는 그룹 포함), 치환 미리보기. Worker에서 실행하고 1초가 넘으면 Worker를 종료해 파국적 백트래킹을 막습니다. |
| 09 | 케이스 변환 | camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE 등 11가지 |
| 10 | 글자 수 | 공백 포함·제외(👨‍👩‍👧 같은 이모지 조합·결합 문자도 한 글자로 셉니다), 한글 2바이트(EUC-KR 기준)·UTF-8 바이트, 단어·줄·문단, SMS·LMS 같은 제한까지 남은 양 |
| 11 | 타임스탬프 | 초·밀리초·마이크로초·나노초 자동 감지, 시간대 선택, ISO 8601·RFC 2822·한국어 표기, 상대 시간, 날짜 → 타임스탬프, 세계 시각 |
| 12 | cron 설명 | 5필드 cron 식을 한국어 문장으로 풀고(요일 7=일요일, `1-7` 범위 지원) 다음 실행 시각 6개를 계산 |
| 13 | UUID | v4·v7 여러 개 생성(대문자·하이픈 없이, v7은 한 밀리초에 많이 만들어도 단조 증가), 붙여넣은 UUID(하이픈 없는 형식·중괄호·`urn:uuid:` 포함)의 버전·변형·v7 시각 해석 |
| 14 | 한글 Lorem | 문단 수 또는 글자 수에 맞춘 자연스러운 한글 더미 문장 |

공통 기능

- **스마트 붙여넣기**: 홈에서 아무 곳에서나 ⌘V(Ctrl+V)를 누르거나 붙여넣기 패드에 넣으면 JSON·JWT·URL·Base64·타임스탬프·색·UUID를 알아보고 알맞은 도구를 제안합니다. 누르면 그 도구에 내용을 채워 엽니다.
- **커맨드 팔레트**(⌘K / Ctrl+K): 한글·영문 이름과 키워드로 도구를 찾아 이동하고, 고정·자동 저장·단축키 안내 같은 동작도 실행합니다.
- **해시 라우팅**: `#/json`, `#/color`처럼 도구마다 주소가 있어 새로고침·북마크·공유가 됩니다.
- **즐겨찾기 고정과 최근 사용**: 별표로 고정하면 사이드바와 홈 맨 위에 보입니다.
- **도구별 입력 자동 저장**: 입력이 멈추고 0.4초 뒤 저장됩니다. 도구 머리글·커맨드 팔레트·설정에서 끌 수 있고, 끄면 저장된 입력도 지웁니다. 실수로 껐다면 알림의 ‘되돌리기’로 저장된 입력을 되살립니다.
- 입력칸마다 **붙여넣기·예시 입력·파일 열기·지우기** 버튼과 **파일 드롭**을 지원하고, 결과는 **복사·다운로드**할 수 있습니다. 입력을 통째로 바꾸는 동작(지우기, 예시 입력, 붙여넣기 버튼, 파일 열기, JSON 정리·압축)은 알림의 ‘되돌리기’로 되돌릴 수 있습니다. 되돌리기 알림은 가장 최근 것 하나만 남고, 다른 도구로 옮기면 닫힙니다.
- **단축키 안내**(⌘/ / Ctrl+/): 전체 단축키와 도구별 단축키(예: JSON ⌘↵ 정리, ⌘⇧↵ 압축)를 보여 줍니다.
- 설정: 예시 데이터 지우기(예시 그대로인 입력만 비움), 백업 JSON 내보내기·가져오기, 전체 초기화(확인 절차).
- **오류 복구**: 한 도구 화면이 깨지면 그 도구만 오류 화면으로 바뀌고, ‘이 도구 입력 지우고 다시 열기’로 저장된 입력 때문에 되풀이되는 오류에서 빠져나올 수 있습니다. 앱 전체가 깨지면 ‘저장된 데이터 지우기’(확인 절차)로 처음 상태로 돌아갑니다.
- **터치 기기**: 손가락으로 쓰는 기기에서는 누를 수 있는 모든 대상이 44px 이상이고, 트리의 경로 복사 버튼도 항상 보입니다.

## 사용 방법

1. 홈에서 다루고 싶은 내용을 붙여넣고 제안된 도구를 누르거나, 왼쪽 목록·⌘K로 도구를 엽니다.
2. 처음에는 도구마다 예시 입력이 들어 있어 바로 결과를 볼 수 있습니다. ‘지우기’로 비우고 내 데이터를 넣으면 됩니다.
3. 결과 패널의 복사·다운로드 버튼으로 결과를 가져갑니다.

## 실행·빌드·테스트

Node.js 20.19 이상이 필요합니다. 테스트는 Node 22.18 이상(타입 제거 기능)과 로컬 Chrome을 씁니다.

```sh
npm install --no-audit --no-fund
npm run dev            # 개발 서버
npm run build          # 타입 검사 + 프로덕션 빌드(dist/)
npm run lint           # oxlint
npm run test:unit      # 도메인 로직 단위 검증(색 정확도, diff 최소성·성능, Base64, JSON 오류 위치 등)
PORT=4311 npm run test:smoke   # 빌드 결과로 실제 사용자 흐름 시나리오 검증(헤드리스 Chrome)
```

`tests/screens.mjs`는 디자인 점검용 스크린샷 스크립트입니다. 미리보기 서버를 띄운 뒤 `BASE_URL=http://127.0.0.1:4311 node tests/screens.mjs`로 실행합니다.

## 기술 구성

- Vite 8, React 19, TypeScript 6(strict), oxlint, playwright-core(테스트)
- 글꼴: Pretendard Variable(본문), JetBrains Mono Variable(코드) — 모두 npm 패키지로 자체 호스팅
- 런타임 의존성은 React와 글꼴뿐입니다. 색 변환(OKLab 행렬), diff(Myers), JSON 오류 위치 스캐너, TypeScript 타입 추론, CSV, cron 해석은 직접 구현했고, 해시·UUID는 브라우저 내장 `crypto`를 씁니다.
- 도구 화면은 처음 열 때 불러오는 코드 분할을 적용했습니다(첫 화면 JS 약 100KB gzip).

```
src/
  lib/        화면과 무관한 순수 함수(색, diff, JSON, Base64, 시간, 정규식, 감지 등)
  state/      localStorage 접근, 설정 스토어, 도구별 상태·자동 저장, 토스트
  tools/      도구 화면(도구마다 한 파일 또는 폴더), 도구 목록·예시 데이터
  components/ 공용 UI(입력 패널, 커맨드 팔레트, 사이드바 등)
  pages/      홈, 도구 틀, 설정, 404
tests/        domain.test.ts(단위), smoke.mjs(스모크), screens.mjs(스크린샷)
```

## 데이터 저장 방식과 개인정보

- 서버·API 키·분석 도구·쿠키가 없습니다. 앱을 불러온 뒤에는 앱 자신의 파일 말고 어떤 네트워크 요청도 하지 않습니다(스모크 테스트가 외부 요청이 없음을 확인합니다).
- 저장은 이 브라우저의 `localStorage`에만 합니다. 키는 모두 `toyz-tiny-tools:`로 시작합니다.
  - `toyz-tiny-tools:prefs` — 고정한 도구, 최근 사용, 자동 저장 여부, 최근 색 (`schema` 필드 포함)
  - `toyz-tiny-tools:tool:<도구>` — 도구별 입력과 옵션 (`schema`, `savedAt`, `data`)
- 저장된 값이 손상되었거나 모양이 다르면 그 필드만 버리고 기본값으로 시작합니다.
- Base64·해시 도구에 넣은 파일은 저장하지 않습니다.

## 알려진 한계

- 40만 자가 넘는 큰 입력은 localStorage 용량을 지키려고 자동 저장하지 않습니다(화면에 “입력이 커서 저장하지 않았어요”라고 표시합니다).
- 텍스트 비교는 800ms 계산 예산을 넘기면 남은 구간을 통째로 삭제·추가로 표시합니다(결과는 여전히 올바른 편집이지만 최소가 아닐 수 있습니다). 화면에는 4,000줄까지 그리고 나머지는 patch로 확인하도록 안내합니다.
- 정규식 강조 미리보기는 앞 10만 자, 캡처 그룹 표는 앞 200개까지만 보여 줍니다. 일치는 최대 5,000개까지 셉니다.
- 조화 색은 HSL 색상환 기준으로 계산합니다. 명도 팔레트는 OKLCH 명도 기준이며 색역을 벗어나면 채도를 줄여 sRGB 안으로 맞춥니다.
- ‘한글 2바이트’는 EUC-KR(완성형) 기준 어림값이라 일부 특수 문자는 실제 인코딩과 다를 수 있습니다.
- cron은 표준 5필드(초 필드가 있는 6필드는 초를 무시)와 `@daily` 같은 별칭만 지원합니다.
- 중첩이 수천 단계를 넘는 JSON은 검증·트리 보기는 되지만, 정리·압축·TypeScript·CSV 보기는 브라우저 호출 스택 한계 때문에 만들 수 없다고 안내합니다.
- 텍스트 비교는 줄 끝 줄바꿈 유무만 다른 경우를 같은 것으로 보고, unified patch에 `\ No newline at end of file` 표시를 넣지 않습니다.
- 줄 안 강조는 한 번의 비교에서 모두 합쳐 0.25초까지만 계산합니다. 긴 줄이 아주 많이 바뀌면 나머지 줄은 줄 전체 색으로만 표시합니다.
- 역사적 시각(1900년 이전 등)에서 초 단위 지역 평균시(LMT) 오프셋은 분 단위까지만 반영합니다.
- JWT 서명은 검증하지 않습니다.
