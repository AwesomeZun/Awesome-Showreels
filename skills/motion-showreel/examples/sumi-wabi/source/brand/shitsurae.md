# しつらえ　余白庵 意匠の手引き

宿の印刷物、ウェブ、映像をつくるときの約束ごとです。
迷ったら、足すより引きます。

## 色

色は伝統色の名で呼びます。
朱は落款（宿の印）ひとつだけに使い、ほかには使いません。

| 名 | 用途 | 値 |
|---|---|---|
| 鳥の子 | 地の色（和紙） | #F2EBDD |
| 生成 | 二番目の地、帯 | #E8DFCD |
| 胡粉 | 紙を重ねるところ | #FAF6EE |
| 墨 | 文字、線 | #1E1C1A |
| 薄墨 | 添え書き | #57524C |
| 鈍色 | 注記 | #67615A |
| 利休鼠 | 淡い面、茶の色 | #7D8272 |
| 朱 | 落款のみ | #C0392B |

- 白は真っ白にせず、黒は真っ黒にしません。紙の色と、墨の色にします。
- 写真を置くときも、彩度を落として紙になじませます。
- 金、銀、グラデーションは使いません。

## 文字

- 書体は、しっぽり明朝 B1 です。墨だまりのある明朝体を選んでいます。
- 見出しも本文も、縦組みを基本にします。
- 文字の大きさは三段までです。宿名、言葉、添え書き。
- 約物は少なく。感嘆符と疑問符は使いません。
- 和文に欧文を混ぜません。ローマ字は、ご予約先の表記にだけ使います。

## 余白

- 紙面の七割には、何も置きません。
- ものは中央に置かず、少しずらします。
- 文字の列は、右から左へ読みます。

## 動き（ウェブと映像）

- 呼吸より速く動かしません。跳ねない、弾まない、揺らさない。
- 現れるときは、墨が紙ににじむように。消えるときは、霧が晴れるように。
- 場面の切り替えは、絵巻をひらくように、右から左へ。
- 止まって見えるときも、紙と霧はいつも少しだけ動いています。

## 音

- 水琴窟の一滴、琴の一音、尺八の息。
- 拍は、ゆっくりとした脈ほどです（一分におよそ七十）。
- 太鼓、手拍子、電子音は使いません。

## 言葉づかい

- です・ます で、短く書きます。
- 使わない言葉　「最高級」「極上」「ラグジュアリー」「映え」「非日常」「癒やし」「激安」「今だけ」
- 言いかえ　「おもてなし」は、何をするのかを具体的に書きます。「絶景」は、見えるものの名前を書きます。

## 落款（宿の印）

- 朱の正方形に、白抜きで「余白」。
- 宿名の左下か、文字の列の終わりに、ひとつだけ押します。
- 傾けません。ふたつ押しません。大きくして飾りにしません。

---

※ 余白庵は、作例のための架空の宿です。
