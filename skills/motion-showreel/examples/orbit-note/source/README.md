# Orbit Note

생각이 연결되는 나만의 노트입니다. 아이디어를 카드로 적고, 끌어서 잇고, 본문에 `[[카드 제목]]`을 쓰면 저절로 엮이는 무한 캔버스 노트 앱이에요. 서버 없이 브라우저 안에서만 동작하고, 데이터는 이 기기의 IndexedDB에 저장돼요.

> toyz 마켓플레이스의 예시 프로젝트를 실제 앱으로 구현했습니다. (“Orbit Note — 생각이 연결되는 나만의 노트”)

## 주요 기능

- **무한 캔버스**: 빈 곳을 끌어 이동하고, 휠·트랙패드 핀치로 커서 기준 확대·축소해요. 확대 컨트롤(−, 100%, +)과 전체 보기 맞춤이 있어요.
- **카드**: 빈 곳 두 번 누르기, `새 카드` 버튼, `N` 키로 만들어요. 끌어서 옮기고, 상세 패널에서 제목·본문·색(6가지)을 고치고, 복제·삭제(되돌리기 알림)해요. Shift 클릭이나 Shift+드래그(또는 선택 도구)로 여러 장을 골라 함께 옮겨요.
- **연결**: 카드 가장자리 점(핸들)을 끌어 다른 카드에 놓으면 방향이 있는 곡선 연결이 생겨요. 빈 곳에 놓으면 새 카드를 만들어 바로 이어요. 연결을 고르면 라벨을 붙이거나 방향을 뒤집거나 지울 수 있어요.
- **위키 링크**: 본문에 `[[카드 제목]]`을 쓰면 점선 연결이 저절로 생겨요. `[[`를 치면 제목을 제안하고, 없는 제목이면 상세 패널에서 새 카드를 만들자고 제안해요. 카드 상세에는 백링크(이 카드를 가리키는 카드)와 나가는 연결 목록이 있어요. 카드 제목을 바꾸면 다른 카드 본문의 참조도 함께 바뀌어요.
- **검색**: `/` 또는 `⌘K`(`Ctrl+K`)로 제목과 본문을 찾아요. 결과를 고르면 카메라가 그 카드로 부드럽게 날아가고 카드가 빛나요.
- **미니맵**: 공간 전체와 지금 보이는 영역을 보여 주고, 누르거나 끌면 그 위치로 이동해요. 캔버스가 좁을 때(좁은 창·태블릿·모바일)는 확대 컨트롤이 도구 막대 위 한 줄로 올라가고, 미니맵은 `미니맵` 버튼으로 펼쳐요.
- **자동 정렬**: 직접 구현한 force-directed(힘 기반) 레이아웃으로 연결된 카드는 가까이, 나머지는 멀리 놓고, 겹침은 마지막에 사각형 기준으로 없애요. 애니메이션으로 옮기고 `⌘Z`로 되돌릴 수 있어요.
- **여러 공간**: 공간을 만들고, 이름을 바꾸고, 전환하고, 지울 수 있어요(삭제는 확인 절차). 주소 `#/space/<id>`로 공간을 바로 열어요.
- **저장**: IndexedDB에 디바운스 자동 저장하고 상단에 저장 상태(저장 대기·저장 중·저장됨·실패 시 다시 시도)를 보여 줘요. 같은 브라우저에서 여러 탭을 열어 두면 한 탭의 저장이 다른 탭에 곧바로 반영돼요.
- **내보내기·가져오기**: 전체 JSON 내보내기·가져오기, 현재 공간 마크다운 내보내기(카드별 섹션과 연결 목록), 현재 공간 PNG 이미지 내보내기.
- **포커스 모드**: 고른 카드와 직접 연결된 카드만 또렷하게 남기고 나머지는 흐리게 해요.
- **실행 취소·다시 실행**: `⌘Z` / `⇧⌘Z`(`Ctrl+Y`), 도구 막대 버튼.
- **모바일**: 한 손가락으로 이동, 두 손가락 핀치로 확대, 탭하면 아래에서 편집 시트가 올라와요. 연결은 `연결` 버튼을 켠 뒤 두 카드를 차례로 탭해요.

## 사용 방법

처음 열면 예시 공간 두 개(‘생각의 궤도’, ‘독서 메모’)가 들어 있어요. 예시 카드에 기능 설명이 적혀 있으니 끌고, 이어 보고, 고쳐 보세요. 오른쪽 위 메뉴(⋯)에서 **예시 데이터 지우기**와 **전체 초기화**를 할 수 있어요.

| 동작 | 데스크톱 | 모바일 |
| --- | --- | --- |
| 화면 이동 | 빈 곳 끌기, Space+끌기, 가운데 버튼 끌기, 화살표 키 | 한 손가락으로 끌기 |
| 확대·축소 | 휠, 트랙패드 핀치, `+` `−` `0`, 확대 컨트롤 | 두 손가락 핀치, 확대 컨트롤 |
| 새 카드 | 빈 곳 두 번 클릭, `N`, `새 카드` | `+` 버튼, 빈 곳 두 번 탭 |
| 카드 편집 | 카드 누르기 → 오른쪽 상세 패널, `Enter` | 카드 탭 → 아래 시트 |
| 연결 | 핸들을 끌어 다른 카드에 놓기, 상세 패널의 `연결 추가` | `연결` 버튼 → 시작 카드 탭 → 이어질 카드 탭 |
| 여러 장 선택 | Shift 클릭, Shift+드래그, `V`(선택 도구)+드래그, `⌘A` | 선택 도구 버튼 → 끌기 |
| 삭제 | `Delete`, 상세 패널 휴지통 → 알림의 `되돌리기` | 시트 휴지통 → `되돌리기` |

## 실행·빌드·테스트

Node.js 20.19 이상이 필요해요.

```sh
npm install --no-audit --no-fund
npm run dev            # 개발 서버
npm run build          # 타입 검사 + 프로덕션 빌드(dist/)
npm run lint           # oxlint
npm run test:unit      # 도메인 로직 단위 테스트(node:test, 44개)
npm run build && PORT=4303 npm run test:smoke   # 헤드리스 Chrome 사용자 흐름 테스트(32개)
```

스모크 테스트는 `vite preview`를 지정한 포트로 띄우고 설치된 Chrome을 `playwright-core`의 헤드리스 모드로 실행해요. 확대 200%에서의 끌기 정확도, 휠 확대 기준점, 핸들 연결, 위키 링크와 제목 변경, 삭제·되돌리기, 검색 이동, 다중 선택, 자동 정렬(겹침 0), 포커스, 미니맵, 공간 CRUD, 새로고침 후 복원(곧바로 새로고침 포함), JSON·마크다운·PNG 내보내기와 가져오기, 키보드만으로 편집, 따로 지운 두 카드를 지운 순서대로 되돌릴 때의 연결 복원, 메뉴·대화상자를 닫은 뒤 포커스 복귀, 좌표가 망가진 파일 가져오기, 두 탭 동시 사용, 좁은 창(900px)의 확대 컨트롤·미니맵, 모바일 터치 이동·핀치·탭 편집·연결 모드·확대 컨트롤, 최소 지원 폭 360px을 포함한 좁은 폭(360·375·384px)에서 도구 막대 버튼이 막대 안에 모두 들어가는지와 확대 컨트롤의 전체 보기를 확인해요. 스크린샷은 `tests/artifacts/`에 남아요.

## 기술 구성

- Vite 8, React 19, TypeScript 6(strict), oxlint, playwright-core(테스트 전용)
- 본문 글꼴은 자체 호스팅한 Pretendard Variable, 보조 라벨은 시스템 고정폭 글꼴
- 외부 런타임 라이브러리 없이 캔버스·레이아웃·PNG 렌더링을 직접 구현했어요. 초기 JS는 gzip 약 109KB예요.

```text
src/
  domain/      순수 함수(카메라 변환, 곡선·사각형 기하, 카드·연결 연산, 위키 링크, 검색,
               force-directed 레이아웃, 가져오기·내보내기 정규화, 조사 처리, 예시 데이터)
  store/       리듀서(공간·선택·실행 취소 히스토리)
  storage/     IndexedDB 저장소, 디바운스 자동 저장 훅, 새로고침 안전망(journal)
  components/  캔버스, 카드, 상세 패널, 검색, 미니맵, 메뉴, 대화상자, 알림
  lib/         파일 내려받기, PNG 렌더링, 미디어 쿼리 훅
tests/
  unit/        도메인·저장 로직 단위 테스트
  smoke.mjs    실제 사용자 흐름 시나리오
```

### 위험 지점을 다룬 방식

- **확대 상태의 끌기 좌표**: 끌기를 시작한 지점의 월드 좌표를 기준으로, 매 순간 현재 카메라로 커서의 월드 좌표를 다시 구해 차이만큼 옮겨요. 끄는 도중 확대·이동이 바뀌어도 카드가 커서 아래에 머물러요.
- **카드 삭제와 연결**: 카드를 지우면 붙어 있던 연결을 함께 떼어 두었다가 되돌리기 때 양 끝 카드가 모두 있는 연결만 되살려요. 두 카드를 따로 지운 뒤 알림의 되돌리기를 어떤 순서로 눌러도 둘 사이 연결이 사라지지 않도록, 아직 되살릴 수 없는 연결은 보관해 두었다가 반대쪽 카드가 돌아올 때 함께 되살려요. 위키 연결은 본문에서 다시 계산해요.
- **저장 경합과 복원**: 저장은 한 줄로 직렬화하고 바뀐 공간만 써요. 페이지가 내려가는 중에는 IndexedDB 트랜잭션이 중단될 수 있어서, 아직 저장하지 못한 변경(입력 중인 제목 포함)을 `pagehide` 때 localStorage에 동기식으로 적어 두었다가 다음 실행 때 IndexedDB로 옮기고 지워요. 이 기록은 탭마다 다른 키에 적어서 여러 탭이 서로의 기록을 지우지 않아요.
- **여러 탭**: 한 탭이 저장하면 `BroadcastChannel`로 알리고, 다른 탭은 저장소에서 그 공간을 다시 읽어 받아 들여요. 받는 탭에 아직 저장하지 않은 변경이 있는 공간은 건드리지 않고(그 탭의 변경이 이어서 저장돼요) 알림으로 알려 줘요. 그래서 오래 열어 둔 탭이 다른 탭의 변경을 통째로 덮어쓰지 않아요.
- **망가진 가져오기 파일**: 좌표는 ±100,000 안으로 자르고 숫자가 아닌 값은 0으로 바꿔서, 아주 큰 값이 확대·정렬·PNG 계산을 무한대나 NaN으로 망가뜨리지 않게 해요.
- **제목 변경과 위키 링크**: 제목은 입력하는 동안 화면에만 반영하고 Enter·포커스 이동 때 한 번에 확정해요. 그래서 중간에 제목이 비거나 다른 카드와 같아져도 참조가 엉뚱하게 바뀌지 않아요. 확정할 때 이전 제목이 유일했다면 다른 카드 본문의 `[[이전 제목]]`을 새 제목으로 바꿔요.

## 데이터 저장 방식과 개인정보

- 모든 데이터는 이 브라우저의 IndexedDB(`toyz-orbit-note` 데이터베이스)에만 저장돼요. 서버로 보내지 않고, 분석 도구나 외부 요청이 없어요.
- IndexedDB를 쓸 수 없는 환경에서는 localStorage(`toyz-orbit-note:fallback`)로, 그마저 안 되면 이 탭의 메모리에만 보관하고 상단에 알려요.
- 새로고침 안전망은 localStorage의 `toyz-orbit-note:journal:<탭 id>` 키에 잠깐 남았다가 저장이 끝나면 지워져요.
- 저장 데이터에는 스키마 버전이 있고, 손상된 항목은 불러올 때 보정하거나 건너뛰어 앱이 멈추지 않게 해요.
- 브라우저 데이터를 지우면 노트도 사라지니, 중요한 내용은 메뉴에서 JSON으로 내보내 두세요.

## 알려진 한계

- 여러 탭에서 **같은 공간을 거의 동시에**(저장되기 전 0.5초 안에) 고치면 합치지 않고 마지막에 저장한 탭의 내용이 남아요. 이때 알림으로 알려 줘요. 다른 공간을 고치거나 한 탭씩 고치면 모두 보존돼요.
- 카드를 수천 장 넣으면 끌기·이동이 느려져요(3,000장에서 한 프레임 약 80ms를 측정했어요).
- 카드 제목을 이미 있는 다른 카드의 제목과 같게 바꾸면, 다른 카드 본문의 참조는 먼저 만든 카드를 가리키게 돼요(상세 패널에 경고가 떠요).
- 본문은 일반 텍스트와 `[[위키 링크]]`만 지원해요(마크다운 서식은 화면에 그리지 않아요).
- 카드 너비는 240px로 고정이고, 크기를 직접 조절할 수는 없어요.
- 같은 방향의 직접 연결은 한 쌍에 하나만 만들 수 있고, 연결선의 휘어짐을 손으로 조절할 수는 없어요.
- 실행 취소 기록은 현재 공간의 최근 80단계까지이고, 공간을 바꾸거나 새로고침하면 비워져요.
- 자동 정렬은 공간 전체에 적용돼요(고른 카드만 정렬하는 기능은 없어요).
- 마우스 휠의 세로 스크롤은 확대·축소로, 가로 성분이 큰 트랙패드 스크롤은 이동으로 처리해요. 트랙패드 두 손가락 세로 스크롤도 확대·축소가 돼요.
- 검색은 지금 열린 공간 안에서만 찾아요.
- PNG 내보내기는 화면을 캡처하지 않고 다시 그리므로 선택·포커스 표시는 빠지고, 아주 큰 공간은 한 변 8000px 안에 맞추느라 해상도가 낮아져요.
- 마켓플레이스 원본 카드에는 기술로 IndexedDB가 표기되어 있었고, 화면은 공통 기준서의 템플릿(React)으로 구현했어요.
