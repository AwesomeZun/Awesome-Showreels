# Büro Zwölf — Gestaltung / Brand sheet

Version 3. One page of rules for print, screen and project films.
Büro Zwölf Architekten, Zürich. Fictional studio, written for a showreel example.

The studio is named after its grid. Everything we draw, print or film sits on twelve columns.

---

## 01 Farben / Colours

Three colours. Nothing else.

| Name | Hex | Use |
|---|---|---|
| Papierweiss / paper | `#F4F3EF` | every ground |
| Schwarz / ink | `#111111` | type, rules, solid fields |
| Signalrot / signal red | `#D52B1E` | one red element per page |

Grey is not a colour. It is ink on paper at a fixed share: 70 % for secondary text (`#555554`), 60 % for captions
and small print (`#6C6B6A`), 15 % for hairlines (`#D2D1CE`), 6 % for grid fields in construction drawings
(`#E6E5E2`). On a black page, secondary text is paper at 65 % (`#A5A4A1`).

- Red marks one thing per page: the hall in a section, the first prize, the square of the wordmark.
- Red is never a tint, a gradient or a background wash. Red text only at 48 px and larger.
- A page is white or black. Black pages are for numbers.

## 02 Schrift / Type

One typeface: Schibsted Grotesk (SIL Open Font License 1.1). Two weights.

| Weight | Use |
|---|---|
| Medium 500 | running text, labels, captions, small print |
| Bold 700 | headlines, numerals, the wordmark |

- Satz: linksbündiger Flattersatz. Flush left, ragged right. Never centred, never justified.
- No italics. Emphasis is weight or size, never slant.
- Lowercase wordmark: **büro zwölf**. Headlines in sentence case.
- Tracking: display −0.03 em, numerals −0.045 em, text 0.
- Sizes on screen (px at 1920 × 1080): 16, 20, 24, 32, 48, 72, 120, 200, 320, 480.
- One size jump per page that is at least five steps. Small text stays small.

## 03 Zahlen / Numbers

Numbers are the headline. Set them large, set the unit small.

- Levels with a sign and two decimals: ±0.00, +3.60, +14.40.
- Dimensions with two decimals and a space before the unit: 7.20 m.
- Thousands with a typographic apostrophe: 4’320 m².
- Numerals in Bold 700. Tables use tabular figures, so columns of numbers align; display numerals stay proportional.
- Numbers change by rolling within their own line, digit by digit. They never fade.

## 04 Raster / Grid

Screen, 1920 × 1080 px:

| | |
|---|---|
| Columns | 12 × 122 px |
| Gutter | 24 px |
| Margins | 96 px left and right, 72 px top and bottom |
| Rows | 6 × 136 px |
| Baseline | 8 px |

- Every edge sits on a column line, a row line or the baseline.
- The grid is visible only in construction drawings (fields at 6 % ink) and in the first frame of a film.
- Corners are square. No rounded corners, no shadows, no glows, no gradients, no textures.

## 05 Wortmarke / Wordmark

The red square, one column wide, then **büro zwölf** in Bold 700, flush left on the same column line.
The square always marks axis 1, the start of the grid. Never recolour it, never rotate it, never set it in outline.

## 06 Zeichnungen / Drawings

Sections and plans are drawn in ink on paper with hairlines for axes and 2 px for cut walls and slabs.
Axes are dash-dot lines with the axis number in a circle above the drawing.
Levels are marked with a filled triangle and the level in Medium 500.
Drawings are never decorated. If a drawing needs a colour, it is the one red element of the page.

## 07 Bewegung / Motion

For project films and screens.

- Elements move along grid lines only: along a row or down a column. No diagonals, no rotation, no zoom.
- Snap, do not float. A move takes one eighth of a beat and stops dead. No overshoot, no bounce, no easing back.
- Changes are hard cuts on the beat. No cross-fades, no blur, no glow.
- Wipes run along the columns, left to right, one column after the other: twelve columns within one beat.
- When a film counts, it counts on the sixteenth notes: one column, one room, one digit per step.
- Lines draw on from the axis they belong to. Numbers roll digit by digit.

## 08 Ton / Sound

- Minimal techno. 124 BPM, 4/4. One bar is 1.935 s.
- A dry sub kick on every beat. Clicks on the sixteenths. One short stab per bar. No pads, no reverb tails, no vocals.
- Every cut and every snap has a click. The sub kick carries the numbers.

## 09 Sprache / Language

- Short declarative sentences. Facts before opinions. Numbers before adjectives.
- German first, English second, separated by a slash: Raster / Grid.
- Swiss spelling: ss, never ß.
- No exclamation marks. No superlatives.
- Never write: iconic, stunning, unique, world-class, state-of-the-art, cutting-edge, award-winning, revolutionary.
- Every page that shows the studio says, in small print: fictional studio and project, demo content.
